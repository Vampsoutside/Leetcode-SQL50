# Leetcode-SQL50

This repository contains my solutions and notes for the **LeetCode SQL 50** study plan.  
The goal is to strengthen SQL skills for technical interviews by practicing a curated set of problems ranging from basic to advanced.

## What’s inside

- Solutions to all 50 problems from the LeetCode SQL 50 list  
- SQL queries written in a clear, interview-friendly style  
- Comments explaining key ideas, patterns, and tricky parts  
- Occasional alternative approaches and optimization notes

## Topics covered

- Basic SELECT, filtering, and aggregation  
- JOINs (INNER, LEFT, RIGHT, SELF)  
- Subqueries and CTEs  
- Window functions (ROW_NUMBER, RANK, LAG/LEAD, etc.)  
- GROUP BY, HAVING, and conditional aggregation  
- Date, string, and numeric manipulations in SQL  

## How to use this repo

1. Browse the problem files (typically named by problem number/title).  
2. Read the SQL solution and accompanying comments.  
3. Try solving the same problem on LeetCode before looking at the solution.  
4. Use the patterns here as a reference when practicing similar problems.

## Tech / environment

- Primary dialect: **MySQL / LeetCode SQL** (standard SQL with minor dialect adjustments where needed)  
- All solutions are tested on LeetCode’s online judge.
